# Security Policy

This project is for educational/security-research purposes only.
Report problems privately through GitHub:
https://github.com/noahtilbury/Discord-Minecraft-AutoSecure/security/advisories/new

Do not open a public issue containing tokens, webhook URLs, mailbox passwords or
secured-account data. We do not accept reports of "vulnerabilities" in
third-party services that this tool interacts with.

If you were sold this source code, you have been scammed - it is published free.
